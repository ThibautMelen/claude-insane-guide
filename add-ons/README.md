# Add-ons - Extensions & Outils Complémentaires

Fonctionnalités complémentaires pour améliorer l'expérience Claude Code, mais non essentielles au workflow de base.

---

## 📋 Add-ons Disponibles

### [VS Code Extension](./vs-code-extension/guide.md)
**Intégration IDE** : Utiliser Claude Code directement dans VS Code

**Fonctionnalités** :
- Sidebar Claude intégrée
- Inline suggestions
- Raccourcis clavier
- Sync settings avec CLI

**Quand utiliser** :
- ✅ Workflow hybrid (IDE + CLI)
- ✅ Projets VS Code natifs
- ❌ Terminal-only workflow

---

### [Statusline](./statusline/guide.md)
**Dashboard temps réel** : Tracking avancement et métriques

**Fonctionnalités** :
- Progression tâches
- Token usage
- Temps session
- Background tasks status

**Quand utiliser** :
- ✅ Workflows longs (> 30min)
- ✅ Monitoring ressources
- ❌ Quick tasks
